# 🧭 부산 공공기관 커리어 로드맵 내비게이터 (v2)

부산교통공사·부산도시공사·부산관광공사의 5년 채용 공공데이터(경쟁률·필기합격선·
신규채용·임용조건) 위에서, 전공·전형별로 **데이터상 유리한 직무와 준비 순서**를
설계하는 커리어 도구.

> v2는 통계 정확도와 공기업 채용 도메인 규칙을 바로잡은 버전입니다.
> 추천 수치는 **과거 통계이며 예측이 아닙니다.**

## 구성
| 파일 | 역할 |
|------|------|
| `app.py` | Streamlit UI (로드맵 · 미스매치 · AI 상담 · 청년인턴 점수 · **공고 적격 체커** 5탭) |
| `busan_data.py` | 3기관 데이터 통합 ETL — (직무 × 전형) 2축 스키마, 가중경쟁률, 합격선 통계, 임용조건 추출 |
| `recommender.py` | 학생 프로필 → 설명가능 직무 적합도 + 로드맵 (블라인드 채용 반영, 가중치 주입) |
| `scoring.py` | 공고 근거 점수 엔진 — 청년인턴 가점, 거주지 요건, 가산점 + **(v2.1) 공고·분야별 어학 적격 판정, 관광공사 계약직(2026-42호) 객체, 면접 배점 시뮬레이터** |
| `gemini_advisor.py` | 데이터·공고 임용조건 근거 AI 서술·상담 (Gemini, 비환각 설계) |
| `data/` | 원천 공공데이터 (data.go.kr) |

## v1 → v2 주요 수정
1. **직무와 전형 분리** — '장애인/보훈/취업지원'을 가짜 '사회배려 직무'로 묶던
   스키마 오류를 제거. (직무 × 전형) 2축으로 저장해 '전기직 일반 vs 사회배려'
   경쟁률을 따로 본다.
2. **가중경쟁률** — 단순평균 대신 총지원/총선발 가중평균. 소규모 공고의 왜곡 제거.
3. **블라인드 채용 반영** — 일반행정은 전공 무관이므로 인문계 페널티(0.8)를 삭제.
4. **자격 중복 제거** — '기사 + 산업기사' 동시 권장을 상위 자격 1개로 정정.
5. **API 비용 방지** — `st.form` 으로 제출 시에만 추천·AI 실행(리런마다 호출 차단).
6. **정직한 명명** — 'AI 합격선 예측/MAE' → '합격선 통계(평균±편차)', 제공기관·결측 명시.
7. **근거 확장** — 공고 임용조건(토익 최저·요구자격·전공제한)을 AI 상담 근거로 주입.

## v2 → v2.1 추가 (관광공사 일반계약직 제2026-42호 반영)
1. **어학 적격을 '환산표'가 아니라 '공고 원문 컷'으로 판정.** 같은 관광공사라도
   계약직 공고는 TOEIC 800 = TOEFL 69 = New TEPS 228, 일반직 공고는 TOEIC 800 =
   TOEFL 91 = TEPS 650으로 **타 시험 컷이 다르다.** 글로벌 환산표(`LANG_EQUIV`)로
   충족을 추정하면 틀리므로, 분야별 시험 컷을 직접 OR 비교한다(`lang_requirement_met`).
2. **공고를 검증 가능한 데이터 객체로 인코딩** (`TOURISM_CONTRACT_2026_42`).
   분야별 인원·근무지·어학요건·면접 배점·가점 규칙을 원문에서 추출(추정 없음).
   ※ '다국어 SNS마케팅'은 이름과 달리 공고에 어학요건이 없어 `None`으로 둔다(1원칙).
3. **면접 배점 시뮬레이터** — 면접 100점(직업기초 60+직무수행 40), 70점 컷,
   가점은 40점 이상자에게만·정렬용으로 반영. 원점수는 '추정 입력값(예측 아님)'으로 명시.
4. **가점합격률(30%) 단서 반영** — 선발 3명 이하 분야는 원칙상 가점 미적용
   (단 응시인원 ≤ 채용인원이면 적용)을 분야별로 안내.

## 로컬 실행
```bash
pip install -r requirements.txt
# data/ 에 원천 CSV/XLSX 배치 (파일명은 busan_data.py FILE_CANDIDATES 참고)
streamlit run app.py            # GEMINI_API_KEY 없어도 폴백으로 전 기능 시연
```

## 배포 (Streamlit Cloud)
1. GitHub push → share.streamlit.io 에서 `app.py` 지정
2. App settings → Secrets 에 `GEMINI_API_KEY` 입력 (코드에 키 금지)
